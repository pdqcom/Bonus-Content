# Exec Whispering

**A companion to the Joshua Tree.** Translating security hype for leadership.

The Joshua Tree tells you what to do. Exec Whispering tells you what to say, to whom, and how often, so leadership hears it from you before they hear it from a push notification.

**[Download the PDF](Exec_Whispering_Joshua_Tree.pdf)**

## What's in this folder

| File | What it is |
| --- | --- |
| [`Exec_Whispering_Joshua_Tree.pdf`](Exec_Whispering_Joshua_Tree.pdf) | The full field guide |
| [`templates.md`](templates.md) | Six copy-paste update templates for Slack or email |
| [`update-cadence.md`](update-cadence.md) | How often to update leadership, by Joshua Tree outcome |

## How to use it

1. Land on an outcome using the Joshua Tree.
2. Grab the matching template from [`templates.md`](templates.md) and fill in the `[BRACKETS]`.
3. Paste it into Slack or email, send it, and hit the next-update time you promised. Check [`update-cadence.md`](update-cadence.md) for how often.
